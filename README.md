# 📂 Projects

## 🔹 Task 1 – Credit Scoring Model

### 📌 Project Overview

The first project focuses on developing a **Credit Scoring Model** using Machine Learning.

The objective of this project is to predict the credit risk of an individual based on financial and credit-related information.

Credit scoring is an important application of Machine Learning because financial institutions can use predictive models to support credit-risk assessment.

---

## 🎯 Objective

The main objectives of this project were:

- Load and understand the dataset
- Explore the available financial features
- Perform data preprocessing
- Separate input features and target variable
- Split the dataset into training and testing data
- Train a Machine Learning classification model
- Generate predictions
- Evaluate the model's performance
